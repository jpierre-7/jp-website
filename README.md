## 🧭 Overview

This website showcases full-stack web development, data analytics, machine learning projects, and systems configuration. It is styled with a custom **Gruvbox Dark** design system complemented by interactive visual elements.

### Key Pages & Highlights

- **Home (`/`)**: Dynamic landing page featuring an interactive mouse-reactive canvas wave field, a rotating photo carousel, and quick highlights of core focus areas.
- **About (`/about`)**: Personal background, leadership roles (Coach at Major League Hacking, President of the HCC Computer Science Association), hobbies (multipitch climbing in Red Rocks, Arch Linux ricing), and a categorized technical skill matrix.
- **Projects (`/projects`)**: Deep-dive showcases into key engineering and analytics work:
  - **US County Health Analysis**: End-to-end data analytics platform processing over 293K public health observations across ~3,000 counties with PostgreSQL, Flask, and interactive Plotly Dash visualizations.
  - **Clarity AI**: 1st Place winner at CodeRed:Astra — real-time educational pulse-checking platform bridging classroom communication gaps.
  - **Personal Dotfiles & Arch Rice**: Modular workstation environment orchestrated with GNU Stow, Niri Wayland compositor, and Neovim.
  - **Applied Machine Learning**: Comprehensive exploratory data analysis and predictive modeling workflows with scikit-learn.

## 🎨 Design & Aesthetics

The site is built around a warm, retro-modern terminal aesthetic:

- **Theme**: Gruvbox Dark palette (warm charcoal `#282828` base with bright amber, aqua, and green accents).
- **Typography**:
  - *Headings*: [Space Grotesk](https://fontsource.org/fonts/space-grotesk)
  - *Body*: [Outfit](https://fontsource.org/fonts/outfit)
  - *Code & Accents*: [Maple Mono](https://fontsource.org/fonts/maple-mono)
- **Interactive Elements**: Real-time canvas particle wave field, frosted glassmorphic containers (`backdrop-blur`), and mobile-responsive layouts.
